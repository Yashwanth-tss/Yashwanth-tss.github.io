# Technology Stack

## Build System & Framework
- **Build Tool**: Vite (v2.9.16)
- **Project Type**: Static website with vanilla HTML, CSS, and JavaScript
- **Package Manager**: npm

## Core Technologies
- **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Custom CSS with CSS Grid and Flexbox
- **Fonts**: Google Fonts (Montserrat, Open Sans, Source Code Pro)
- **Icons**: Font Awesome 6.4.0

## Key Libraries
- **AOS (Animate On Scroll)**: v2.3.4 - Scroll animations
- **Typed.js**: v2.0.16 - Typewriter effect animations
- **Form Handling**: Formspree integration for contact form

## Common Commands

### Development
```bash
npm run dev          # Start development server
npm run build        # Build for production
npm run preview      # Preview production build
```

### Installation
```bash
npm install          # Install dependencies
```

## Architecture Notes
- Single-page application with smooth scrolling navigation
- Responsive design with mobile-first approach
- Form validation and security measures implemented
- External CDN resources for fonts and icons
- Modular CSS with CSS custom properties (variables)
